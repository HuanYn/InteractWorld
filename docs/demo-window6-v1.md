本页记录选定的异步 Demo 版本，整理于 2026-09-13。展示使用自训 Action
R005 step1040，在 Wan2.2-TI2V-5B 基座上接入动作 Adapter 与 LoRA，按
**6 + 6 + 3 秒**续写。它是已归档单场景结果的公开参数说明，不是画质、
可靠动作控制或实时性能已通过的发布声明。

[JSON 版本说明](demo-window6-v1.json)仅供阅读和比对，**不是可执行的 rollout
或 deployment 配置**，不包含运行路径、模型资产或任何运行授权。

## 续写协议

父 Action 阶段使用 **49 个 RGB 帧的训练窗口**。选定展示把推理窗口扩大为
25 / 25 / 13 个 latent 帧，分别解码出 97 / 97 / 49 个 RGB 帧。这是推理侧的
分窗续写，不表示该 checkpoint 已在这些较长窗口上训练。

每个后续窗口重新编码上一窗口生成的浮点 RGB 末帧，在转为 uint8 前取值。
两个重复条件帧各丢弃一次，得到 `97 + 96 + 48 = 241` 帧；第 0 帧保留提交的
首图。推理不读取真实未来帧，不靠循环播放或插帧补足时长。

噪声由 seed 42 的单一 CPU 随机生成器依次生成五份 FP32 张量，保留其中 60 个
有序未来 latent 槽，再分成 24 / 24 / 12，不新增随机抽样。这是网页 RGB 输入、
末帧重编码协议；不能与另一个冻结 latent／冻结噪声回归协议合并统计。

## 已观察到什么

历史网页任务已完成生成和播放检查。该单例的总处理时间为 **139.111 秒**；
这是归档观测，不是当前代码的速度测试、跨硬件承诺或实时生成指标。16 FPS
指输出视频的播放帧率。该案例中人物能保留到末尾，抬头段可见天空与山脊，
同时仍有模糊、肢体轮廓变形和细节软化。

最终选定的这组 `window6` 配置尚无完整的同权重、同输入、同噪声
真实动作／全零动作／打乱动作对照。因此不能把单例观感或 HUD 亮键当作
控制准确率提升，也不能宣称跨场景稳定、长期稳定或实时交互已经达标。
后续实验入口不自动替换这个展示选择。
